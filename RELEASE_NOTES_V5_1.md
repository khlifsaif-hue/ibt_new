# SmartCare V5.1

## User Management
- Preserves all V5 behavior.
- Adds a fourth clickable **Disabled users** summary card.
- Clicking the card filters the Company users table to inactive/disabled accounts only.
- The disabled view shows the number of blocked accounts and provides **Show all users** to return to the full list.
- Existing Activate action remains available for each disabled account.
- Summary cards use a responsive four-column desktop / two-column tablet / one-column mobile layout.
