# SmartCare V5

## Users dashboard interaction
- Total Users summary card is clickable and restores the full company user list.
- Active Users summary card is clickable and filters the table to active accounts only.
- Roles Configured summary card opens a role overview with user counts and user names by role.
- Added hover, focus, selected-state and mobile styling for the interactive cards.
- Existing user management, invitation, activation/deactivation and authorization behavior remains unchanged.
